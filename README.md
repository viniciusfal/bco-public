# bco

**bco** is a registration system for BCOs aimed at transportation companies that rely on turnstile management. The system provides an efficient solution for controlling and recording access control devices, simplifying administration.

## 🛠️ Technologies Used
- **Next.js**: React framework for web application development.
- **TypeScript**: A superset of JavaScript that adds static types.
- **TailwindCSS**: A utility-first CSS framework for styling.

## 🚀 Features
- Registration and management of BCOs and BTCS in compliance with ANTT (National Agency of Land Transportation.) standards.
- Recording of information for transportation companies.
- Automation of calculations and turnstile control.
- Intuitive and extremely user-friendly interface.
- Everything runs in the browser - Save data in your browser's local storage until you export your spreadsheet to PDF.
